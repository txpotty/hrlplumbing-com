    Farmhouse Sink Plumbing in Kettering, OH

    Apron-Front Sinks in Kettering, OH

    Apron sinks need a cabinet cut to fit the front panel, and the sink has to be in place before the counter is templated. We set the sink and frame early, so the fabricator measures from the actual bowl instead of a spec sheet. That avoids an uneven reveal. Cast iron versions can top 150 pounds, so we bring two people.

    Composite Sink Installation in Kettering

    Granite and quartz composite sinks are tough on top but can chip at the drain opening if a strainer is overtightened. We tighten by hand first. Most composite brands want silicone rather than putty under the strainer because putty can stain them, so we go by the maker's instructions.

    Workstation Sink Installation in Kettering, OH

    Workstation sinks have a ledge for cutting boards, colanders and drying racks, and many are deep single bowls with the drain off center. The trap layout follows the offset drain, which lets the disposal fit and leaves storage room on one side. Check the faucet reach as well.

    Sink and Disposal Installed Together in Kettering, OH

    Adding a disposal costs least when the sink is already out. We mount the disposal on the new flange, set the trap height for its outlet, and knock out the dishwasher plug so the hose has somewhere to go. You also need power. We check for a switched outlet in the cabinet.
